Sincronização automática: entre na conta e baixe seus dados uma vez para ativar.

Após entrar, baixe os dados uma vez neste dispositivo para ativar a sincronização automática. Alterações serão enviadas automaticamente; mantenha apenas um dispositivo editando por vez. Antes de baixar da nuvem, salve um backup local. A primeira configuração exige criar a tabela e ativar políticas RLS no Supabase; veja as instruções que acompanham este arquivo.
